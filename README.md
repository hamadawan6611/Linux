 📁 Basic `ls` Commands Practice

Here are the commands I've been practicing today:

| Command | Description |
|---------|-------------|
| `ls` | Display only file/folder names |
| `ls -l` | Show detailed list (size, date, permissions) |
| `ls -a` | Show hidden files as well |
| `ls -la` | Show everything in detail (including hidden files) |
| `ls -lh` | Show file sizes in human-readable format (KB, MB) |
